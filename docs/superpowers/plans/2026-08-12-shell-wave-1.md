# Shell Overhaul Wave 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persona-first shell (sidebar ≤25 links/role, clean header), a shared screen system (page_shell / empty_state / stat_card / section_card macros), and rebuilt Dashboard (two modes) + AI Chat, verified by screenshots at 1024/1280/1440.

**Architecture:** Server-side rendering only — the sidebar is filtered in Jinja from a single role→zones structure in `app/utils/role_access.py` (the current Alpine `roleVisible` opacity-dimming is removed; links absent for a role are absent from the DOM). New macros live in `app/templates/macros/page_shell.html` and are the only sanctioned page header / empty state / stat card. Dashboard mode is chosen server-side from row counts. A new `sidebar-links` verify gate renders the sidebar per role and fails on budget overrun.

**Tech Stack:** Flask/Jinja2, Tailwind v3 via `scripts/build_css.py` (CLI at `scripts/bin/tailwindcss.exe`), Alpine.js, pytest.

**Spec:** `docs/superpowers/specs/2026-08-12-shell-overhaul-design.md` — its Principles section is binding.

## Global Constraints

- Never invent data: `None` → `—` (via `|dash`), never a literal 0 for "not computed" (`fabricated-data` gate).
- DESIGN.md token rules: semantic classes only; text on its own tint uses `-emphasis` variants; design-tokens ratchet is 0 and must stay 0.
- Editing template classes requires `python scripts/build_css.py` and committing the rebuilt `app/static/css/tailwind-output.css`; `python scripts/build_css.py --check` must pass at every commit that touches classes.
- Cross-module links guard with `{% if 'endpoint' in flask.current_app.view_functions %}` (blueprints register non-fatally).
- No `console.log` in shipped templates/JS; notifications via `Platform.toast`.
- Tests use shared fixtures from `tests/conftest.py` (`db_session`, session-scoped `app`, `make_org`); `TEST_DATABASE_URL=postgresql://postgres@127.0.0.1:5439/archie_test`.
