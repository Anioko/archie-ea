# allowed_config.txt — the ONLY things allowed to be flag-gated / default-off.
#
# RULE: product features ship ON and wired. A name may live here ONLY if it is
# OPERATIONAL config, never a product feature:
#   - external secrets/keys are auto-exempt by suffix (_API_KEY, _SECRET, ...)
#   - deploy-environment selectors
#   - infrastructure / performance / observability toggles
# Every entry needs a one-line reason. Adding a PRODUCT FEATURE here is a governance
# breach — the no-dark-features gate exists precisely to stop that.
